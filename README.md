# endap.js
another unspecialized js library


## fork
+ Click **Fork** button near top right corner.


## git
+ Install Git for Windows from https://git-scm.com/install/windows.


## cli
+ Open File Explorer to your working folder.
+ Open Git Bash with right click.
+ Scroll down and choose Show more options.
+ Click Open Git Bash here.


## clone
+ Notice your GitHub username, e.g. `myuser`.
+ Clone the `endap.js` fork from your GitHub.
  ```bash
  $ clone https://github.com/myuser/endap.js
  ```
+ Change directory to `endap.js`.
  ```bash
  $ cd endap.js
  ```
+ List available files and folders.
  ```bash
  $ ls
  ```


## commit
+ Modify files or folders or create ones.
+ Check local repository status
  ```bash
  $ git status
  ```
+ Add new files if necessary, e.g. `new-file-name`.
  ```bash
  $ git add new-files-name
  ```
+ Commit changes.
  ```bash
  $ git commit -am "update new file"
  ```
+ Push commited changes.
  ```bash
  $ git push
  ```


## close
+ Close Git Bash if no longer used.
```bash
$ exit
```
+ Or simply close the window.


## python
+ Install Python for Windows from https://www.python.org/downloads/.


## server
+ Open Command Prompt on Windows.
+ Run HTTP server
```
$ python3 -m http.server 8000
```
+ Open a web browser, e.g. Chrome.
+ Type in the address `http://localhost:8000`.
+ Find `modules` and open `xx` as instructed in a session.
+ To close HTTP server press CTRL+C in Command Prompt.
+ Type `exit` or simply close the window.


## editting
+ Install a plain text editor, e.g. Notepad++ from https://notepad-plus-plus.org/downloads/ or other one of your choice.
+ Open it and create files or folder in `endap.js/module/xx`.
+ Remember to add, commit, and push using Git for any changes.
